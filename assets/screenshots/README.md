# Screenshots

Release screenshots should use synthetic or explicitly approved demonstration
prompts, targets, and results. Never capture authenticated supported-site pages,
account identifiers, private conversations, cookies, or customer data.

`dashboard.png` is rendered from the local dashboard with a mocked empty
extension state and is suitable for repository documentation.

The workflow screenshots are:

- `Dashboard prompt.png` — populated campaign inputs and engine selection;
- `Run result.png` — completed-run status and visibility summaries;
- `Run result2.png` — recent result cards and match evidence;
- `Exported CSV.png` — the row-oriented CSV export in a spreadsheet; and
- `Exported HTML Report.png` — the standalone prompt-details report.

The workflow screenshots contain the demonstration target name `Sibi Mark`,
example prompts, generated response excerpts, and visible source fragments.
Confirm that this demonstration material is approved for public distribution
before publishing the repository.
